# ZenScripts

Userscripts and small Windows tools for calmer, cleaner computing.

## Userscripts

| Script | What it does |
|---|---|
| [whatsapp-toggle-sidebar](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/whatsapp-toggle-sidebar/whatsapp-toggle-sidebar.user.js) | Hides or shows the chat list with Ctrl+Alt+B |
| [wikipedia-seamless-background](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/wikipedia-seamless-background/wikipedia-seamless-background.user.js) | Fixes Wikipedia's mismatched background colors |
| [x-clean-left-sidebar](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/x-clean-left-sidebar/x-clean-left-sidebar.user.js) | Hides Calls, Creator Studio and Premium |
| [x-download-images-button](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/x-download-images-button/x-download-images-button.user.js) | Saves a post's images at original quality |
| [x-hide-analytics-banner](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/x-hide-analytics-banner/x-hide-analytics-banner.user.js) | Hides the "Access your post analytics" banner |
| [x-hide-creator-subscribe-button](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/x-hide-creator-subscribe-button/x-hide-creator-subscribe-button.user.js) | Hides creator "Subscribe" buttons |
| [x-hide-not-verified-banner](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/x-hide-not-verified-banner/x-hide-not-verified-banner.user.js) | Hides the "not verified yet" banner on profiles |
| [x-hide-subscribe-button](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/x-hide-subscribe-button/x-hide-subscribe-button.user.js) | Hides the Premium card in the sidebar |
| [x-hide-whats-happening](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/x-hide-whats-happening/x-hide-whats-happening.user.js) | Hides the trending box in the sidebar |
| [youtube-no-translate-button](https://raw.githubusercontent.com/toshiotomikawa/ZenScripts/main/youtube-no-translate-button/youtube-no-translate-button.user.js) | Removes the translate button from comments |

Install [Tampermonkey](https://www.tampermonkey.net/) or [Violentmonkey](https://violentmonkey.github.io/), then click a script's name. Installed scripts update from this repository.

## AutoHotkey

Run with [AutoHotkey v2](https://www.autohotkey.com/).

- [`ExplorerPasteIntoSelectedFolder.ahk`](autohotkey/ExplorerPasteIntoSelectedFolder.ahk) pastes into the selected folder in File Explorer; `Ctrl+V` works as usual otherwise.
